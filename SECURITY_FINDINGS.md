# Harbour Wallet security findings (audit of 2026-11-16)

Branch `security/audit-2026-11-16` (from `codebase-structuring` at `c01e037`). Paths are relative to the repository root; `EXT` = `harbour-wallet-v3/apps/extension`, `BE` = `harbour-wallet-v3/apps/backend`. Plain-language explanations with the same numbers are in `SECURITY_EXPLAINED.md`.

**Two passes on 2026-11-16 / 17.** Rows 1 to 20 are the first pass. Rows 21 to 29 are the second pass, which did not rely on the earlier documents: the backend was built and run in an isolated Linux sandbox and attacked over HTTP, and the production extension build was loaded in a real (headless) Chromium and attacked from a test web page.

**What was verified in the second pass (run by me, in the sandbox):** backend `go build ./...`, `go vet ./...`, `go test -race ./...` (all packages pass) and the integration tests against a real Postgres 16 and Redis (`internal/api`, `indexer`, `prices`, `store`: pass); the API and rpc-gateway running with Postgres, Redis, NATS and a fake RPC node that records what it receives; extension `npm ci`, unit tests 592/593 (the one failure, `test/chains.test.js`, only needs the `research/` folder, which was not copied to the sandbox), ESLint with zero warnings, `tsc --noEmit` and a production `vite build`; the built extension in Chromium: wallet creation, storage contents, every outbound request, the dApp provider and the approval data. **Differences from production that limit what the run proves:** Go 1.27.4 was used (the sandbox cannot download 1.26.10; `go.mod` was not changed), the database ran without TLS and with the owner login (no per-service roles), no real provider keys or network (Alchemy, Infura, CoinGecko and the rest were unreachable), no Centrifugo, no Docker. **Not run in either pass:** `govulncheck`, `gosec`, the GitHub Actions workflows, the Railway images, a headed browser with the real popup UI clicked by hand, biometrics hardware, a Ledger. From the first pass: the owner ran Docker Compose, `./run.sh smoke` and `go test -race ./...` on the Mac on 2026-11-16.
