# Documentation

- `harbour/` — release process, security model, store listing for Harbour Wallet.
- `project/` — build log and decisions, implementation plan, feature matrix, coverage tracker, agent charter (`AGENTS.md`).
- `re/` — reverse-engineering findings on the Trust Wallet extension: notes, backend map, UI parity, design system, ledgers.
- `trust-wallet-architecture/` — architecture write-up of the reference extension and the Harbour parity plan.

Current implementation status is tracked in
[`project/V3-STATUS.md`](project/V3-STATUS.md). It is the authoritative status
for the `harbour-v3` branch. The older project matrix, build log, and UI parity
documents contain historical v2 snapshots unless they are explicitly marked
with a later v3 update.

Raw evidence (captures, extracted files, JSON output) lives in [`../evidences/`](../evidences/README.md), not here.
