# Harbour Wallet

A self-custodial crypto wallet: a Chrome (Manifest V3) extension and a Go backend. This repository also holds the reverse-engineering research the wallet was built from.

```
.
├── harbour-wallet-v3/
│   ├── apps/extension/       Chrome MV3 extension (TypeScript, React, Vite)
│   ├── apps/backend/         Go services (api, rpc-gateway, indexer, webhook-ingest, price-poller, tx-tracker, notifier, realtime-bridge, migrate)
│   └── infra/railway/        Railway config-as-code, one file per service
├── documentation/            All guides. Start at documentation/README.md
├── research/                 Reverse-engineering evidence, tools and write-ups (not needed to build or run)
├── scripts/git-hooks/        Pre-commit secret guard
└── .github/workflows/        CI: extension.yml, backend.yml; dependabot.yml
```

## Quick start

You need Node 22, Docker, Chrome 137+, and an Alchemy or Infura API key. Full steps and troubleshooting: [documentation/how-to-run.md](documentation/how-to-run.md).

```bash
# 1. backend (first run stops and asks for an RPC key in apps/backend/.env; add it and rerun)
cd harbour-wallet-v3/apps/backend
./run.sh
./run.sh smoke

# 2. extension
cd ../extension
npm ci
cp .env.example .env.production
npm run build        # then chrome://extensions > Developer mode > Load unpacked > dist/
```

Checks: `npm run verify` (extension), `make test` (backend). Install the secret guard once: `ln -s ../../scripts/git-hooks/pre-commit .git/hooks/pre-commit`.

## Secrets

Never committed (git-ignored): every `.env`, `harbour-keys.env`, `harbour-config-key.json`, `harbour-release-key.json` and the Firebase service-account file. `apps/backend/.env` is generated by `scripts/setup.sh`. `assets/` is a local clone of an icon library used only by `apps/extension/scripts/import-assets.py`.
