# Railway config-as-code

One file per Railway service. In the Railway dashboard, for each service set **Root Directory** and **Config as code → file path** as written in the first comment line of its file (the file path is absolute from the repository root, for example `/harbour-wallet-v3/infra/railway/api.toml`).

Full walkthrough, variable list and known trade-offs: [documentation/harbour-v3/operations/railway-deployment.md](../../../documentation/harbour-v3/operations/railway-deployment.md).
