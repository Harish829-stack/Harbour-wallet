# Harbour extension

Chrome Manifest V3 wallet. TypeScript, React, Vite (`@crxjs/vite-plugin`), `@trustwallet/wallet-core` (WASM) for cryptography.

| Path | What it is |
| --- | --- |
| `src/background/` | Service worker: vault, signing, dApp provider, message handlers |
| `src/core/` | Wallet logic: chains, keys, transactions, swaps, staking, NFTs, backend client |
| `src/popup/` | React UI |
| `src/inpage/`, `src/content/` | Injected dApp provider and content script |
| `src/offscreen/` | Offscreen clipboard page |
| `public-production/` | Static assets copied into the build (logos, fonts, illustrations); `inpage.js`, `public-content.js`, `wallet-core.wasm` inside it are generated by the build |
| `scripts/` | Build, verify, release, chain-registry generators, signing tools |
| `test/` | Unit tests (`node --test`) |
| `config/`, `releases/`, `release-signer.pub` | Signed remote config, signed release metadata, pinned release signer |
| `gateway/` | Legacy Cloudflare Worker gateway, replaced by the Go backend's `/v1/gw`; kept because `test/` still covers it. Not deployed |
| `tools/` | Manual audit harnesses (UI layout screenshots, mitm e2e) |

```bash
npm ci                            # Node 22 (.nvmrc), install scripts disabled on purpose (.npmrc)
cp .env.example .env.production   # VITE_HB_API_URL must be https:// for a release build
npm run dev                       # live development
npm run build                     # dist/
npm run verify                    # lint, tsc, tests, build, npm audit gate, secret scan
node scripts/release.mjs          # signed release zip; see documentation/harbour-v3/operations/release.md
```

Scripts that read research data (`gen-chain-registry.mjs`, `gen-extra-chains.mjs`, `test/chains.test.js`) read from `../../../research/evidences/`. Release and gateway scripts read local key files (`harbour-release-key.json`, `harbour-keys.env`) from the repository root.
